# 🎬 Cinema Booking System

Современная и надежная система бронирования билетов в кинотеатре, написанная на **Go** и **Postgres**. Проект включает в себя интерактивный фронтенд и отказоустойчивый бэкенд с защитой от race condition (гонки данных).

## 🚀 Ключевые особенности

*   **Concurrency Safety (ACID):** Бронирование мест защищено от конкурентных запросов. Использование транзакций уровня базы данных и блокировки строк `FOR UPDATE` исключает ситуацию, когда два пользователя могут купить один и тот же билет одновременно.
*   **Контексты и таймауты:** Все запросы к БД ограничены жесткими таймаутами (`context.WithTimeout`), что предотвращает зависание сервера при высокой нагрузке.
*   **Автогенерация зала:** Система автоматически генерирует схему зала при создании или запросе нового сеанса.
*   **Современный UI:** Интерактивный 3D-зал кинотеатра с неоновой подсветкой экрана проектора, визуальными эффектами объема кресел и встроенным таймером бронирования.

🔧 Архитектурное решение: Защита от Race Condition
Главная гордость этого проекта — хэндлер бронирования BookSeats. Чтобы избежать ситуации «double booking» (двойного бронирования), логика использует блокировку на уровне строк базы данных PostgreSQL:

Go
// Фрагмент транзакции из handlers/handlers.go
query := `SELECT id, status FROM seat WHERE id = ANY($1) FOR UPDATE`
Как это работает:

При начале транзакции инструкция FOR UPDATE временно блокирует выбранные строки кресел для других транзакций.

Если второй пользователь пытается выбрать те же места, его запрос будет ждать, пока первая транзакция не сделает Commit или Rollback.

Если первый пользователь успешно покупает билет, статус меняется на booked. Транзакция второго пользователя разблокируется, видит измененный статус и безопасно возвращает ошибку 409 Conflict, защищая систему от сбоя.
